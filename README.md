# Искра в эфире · Фонтейнка

Статическая игра для зоны Пенаконии на CONstanta. Гость сканирует QR на маленьком деревянном сундучке, обмотанном изолентой, переписывается с Искрой от лица Первопроходца и играет в маленького «Сапёра» прямо в чате.

## Правила

- Короткий вход «Войти на стрим». Переписка идёт с паузами, анимацией сообщений и индикатором «Искра печатает».
- От трёх до пяти минут **активной игры** в зависимости от сложности: отсчёт начинается при открытии первого поля. Во время сюжетных реплик и между попытками время стоит; обновление страницы сохраняет остаток.
- Изначально пять попыток. Попадание на мину тратит попытку. Когда время впервые заканчивается, Искра один раз дарит ещё минуту и одну попытку; после сообщения игра продолжается на том же поле.
- Сложность выбирается ответом в диалоге: лёгкая — 5 × 5 / 4 мины / 3 минуты, средняя — 6 × 6 / 7 мин / 4 минуты, сложная — 7 × 7 / 10 мин / 5 минут.
- Победа с первой попытки быстрее минуты вызывает **один** реванш: Искра паникует, повышает сложность на ступень и открывает новое поле. После сложного уровня — «Паника Искры», 8 × 8 / 14 мин, общий бюджет 6 минут. За повышение уровня добавляется минута, уже потраченное время и попытки сохраняются; повторного реванша нет.
- Первый ход и все соседние клетки безопасны на любой сложности. Для победы нужно открыть все клетки без мин; сами флажки победу не дают.
- Внизу Искра наблюдает за игрой в отдельном облачке: реагирует на ходы, серии успехов, ошибки, флажки, бездействие, нехватку времени и близкую победу. Более 160 реплик, приоритет событий, паузы между комментариями и память уже сказанного. Панель оформлена как маленькое окно стрима с анимированными реакциями; появляется только во время активной игры и сразу исчезает после завершения раунда. Эти короткие реакции не блокируют игру.
- При победе площадка спасена. После исчерпания попыток или дополнительной минуты — срабатывает в сюжете игры — раунд проигран. Оба финала предлагают показать экран стендовику и получить печать. На площадке используется маленький деревянный сундучок, обмотанный изолентой, с QR-кодом.

## Запуск

Для сборки обеих игр — Node.js 22.12+. Production-сервер поддерживает Node.js 20+.

```sh
npm ci
npm run dev
```

Открой адрес, который напечатает Vite. Для просмотра с телефона в той же сети: `npm run dev -- --host 0.0.0.0`.

```sh
npm run build
npm run preview
```

«Искра в эфире» остаётся автономной игрой на `/`. Отдельная страница `/robots/` — Новый Бойцовский клуб: два телефона, серверные комнаты, бой до пяти побед и 180 HP. После `npm run build` запускай `npm start`: обе игры работают на порту 3001. WebSocket `/robots/ws` нужен только Бойцовскому клубу; исходная игра по-прежнему сохраняет прогресс локально. Подробнее — [размещение](DEPLOY.md).

Вход на телефоне запрашивает полный экран и горизонтальную ориентацию. Перед боем — мастерская, авторский устав, краткие инструкции и 48-секундная кат-сцена. Все пять разговорных записей и шесть новых реплик воспроизводятся из готовых MP3; серверный TTS не требуется. [Происхождение голосового пакета и воспроизведение генерации](games/robots/docs/generated-voice-pack.md).

## Сессии и QR

Игра сохраняется в `sessionStorage` текущей вкладки после каждого действия: переписка и очередь реплик, поле, сложность, реванш, остаток времени, дополнительные минута и попытка, комментарии Искры, результат. Обновление страницы восстанавливает ту же партию; время активного поля продолжает идти в фоне; пауза между попытками сохраняется. Реплики после возвращения появляются по очереди. Новая вкладка обычно начинает новую сессию, но браузер может скопировать сохранение при дублировании вкладки или восстановить её после закрытия. Вкладки не синхронизируются. Это локальный игровой прогресс, не защита от намеренного сброса.

Страница `/?staff=1` создаёт PNG с QR на введённый публичный адрес. Корневой адрес сайта достаточен, секретные параметры не нужны. Старые пути `/guest` и `/actor` также поддерживаются на хостинге с SPA fallback.

Эфир, его зрители и комментарии Искры — художественная часть игры. Камера и микрофон не используются, сообщения никуда не отправляются.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium --only-shell
npm run test:e2e
```

Тесты проверяют всё дерево диалогов, границы поля, безопасный первый ход, пять или шесть попыток, лимиты времени по сложности, паузы таймера, одноразовый бонус, реванш, комментарии, победу, восстановление после перезагрузки и перенос старых сохранений, независимость сессий, мобильный интерфейс с областью просмотра от 320 × 480, изменение высоты браузера, подсказки на высоких экранах и отступы после поля, длинные комментарии, отсутствие панели после завершения раунда, режим уменьшенной анимации, игру без сети после загрузки и содержимое QR-кода.

## Редактирование

- `client/src/game/dialogue.ts` — все реплики и ветки. `game` в поле `next` открывает сапёра.
- `client/src/game/game.ts` — переходы состояний, время, попытки и финалы.
- `client/src/game/difficulty.ts` — размеры полей и число мин.
- `client/src/game/commentary.ts` — правила выбора живых реакций, их банки и защита от повторов.
- `client/src/game/minesweeper.ts` — поле и правила сапёра.
- `client/src/game/SparxieGame.tsx` — интерфейс, сессионное сохранение и QR.

## Бойцовский клуб

Исходники и готовые материалы находятся в `games/robots/`. Они синхронизированы из `hsr-robots-battle`; точный исходный коммит записан в `games/robots/UPSTREAM.json`. Обновление: `npm run sync:robots -- <путь-к-checkout>`, затем `npm test` и `npm run build`. Скрипт копирует только отслеживаемые Git игровые файлы и не захватывает PSD, ключи и локальные артефакты.
