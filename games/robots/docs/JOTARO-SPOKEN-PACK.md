# Джотаро: пакет по одобренному Original B

28 записей p1: четыре реплики кат-сцены и обе разговорные роли в двенадцати предраундовых парах. Каталог `shared/generated-jotaro-voice-clips.js`, MP3 — `public/assets/voices/spoken-v2/`. Прежний пакет со спроектированным голосом отвергнут пользователем и полностью заменён; его синтезированный WAV-источник удалён из текущей ветки. Дио, эффекты, общий каталог и игровой таймлайн здесь не меняются.

Пользователь прослушал **Original B — усиленные акценты** и одобрил именно его: «хорош!». Это `faceoff-challenge-p1`, **«Хватит пафоса! Покажи, на что СПОСОБЕН!»**, **4,460 с**, SHA-256 `b70455f4432e6b4cc56d989c0cf17734e87e21a7bf5f2440cc35cec814642544`. Файл скопирован побайтно без пересинтеза и перекодирования. Остальные **27**, включая mode, заново синтезированы тем же способом. Одобрение на слух не распространяется автоматически на новые файлы: проверены текст и сигнал, но полная слуховая приёмка не заявляется.

## Источник и рецепт

Референс — пользовательский **«Джот - Ублюдок, ДЫО.mp3»**, сохранённый как `public/assets/voices/jotaro-dio.mp3`, SHA-256 `17bad1ef01499370b836f7a5d5761b9150d6fa23036124c095e951a54e883741`. Используется **весь файл 0–4,2849791667 с**, точный текст **«Ублюдок! Дио!»** подтверждён независимым ASR при подготовке принятого пилота. Внутренняя пауза и оба слова остаются. Источник не смешивается с голосом Дио и не заменяется отдельным коротким криком.

Обработка входа повторяет B: декодирование 48 kHz, среднее двух каналов, запись и чтение PCM16 WAV. SHA reference WAV — `03dc4f5f6e8cce681c6e388b78766879e581cf59a7bbead15f55b4f7cb7c1c1b`. Затем один `create_voice_clone_prompt(ref_audio=(reference,48000), ref_text="Ублюдок! Дио!", x_vector_only_mode=False)`; все новые фразы используют **один и тот же** `voice_clone_prompt`. VoiceDesign, нового описанного голоса, изменения высоты или скорости здесь нет.

Модель [Qwen3-TTS-12Hz-1.7B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base), revision `fd4b254389122332181a7c3db7f27e918eec64e3`, Apache-2.0; SHA-256 веса `38fc7fc51c5e776e840414b6fd443962e9411b9654888fd7913e4da643cb857c`. Метод — [full ICL с повторным использованием профиля](https://github.com/QwenLM/Qwen3-TTS#voice-clone). Параметры: seed **62101**, Russian, BF16/SDPA, non-streaming, `max_new_tokens=240`, `temperature=.9`, `top_k=50`, `top_p=1`, `do_sample=True`, `repetition_penalty=1.05`. Эмоциональный `instruct` у Base не выдумывался.

## Слова и акценты

Каждая строка p1 в `scripts/voice-production/spoken-script.json` содержит **`synthesisText`** — точный вход модели. В нём естественная усиленная пунктуация и смысловой акцент по `emotionalDirection`, а не повсеместный верхний регистр. Например: «Боевой режим! Кабачковое ПРОТИВОСТОЯНИЕ!», «Подойди! Проверим твою СБОРКУ!», «Это инструкция от ЧАЙНИКА.», «Готовь ЛАСТИК! Будешь исправлять!».

Порядок и состав слов `synthesisText` обязаны совпадать с каноническим `text`; генератор останавливается при добавленном, удалённом или изменённом слове. В предраундовых парах канонический `text` и субтитры одинаковы у p1/p2. Только `faceoff-challenge-p1` обновлён на точную запись принятого B. В отчёте сохранены оба поля; усиленный регистр не считается новым словом.

## Проверка и обработка

ASR — локальный [Whisper large-v3-turbo](https://huggingface.co/openai/whisper-large-v3-turbo), revision `41f01f3fe87f28c78e2fbf8b568835947dd65ed9`, русский, beam=5, без подсказки целевого текста и предыдущего контекста. Сравнение строгое по границам/порядку слов, с нормализацией только регистра, пунктуации и ё/е. Примесь слов референса — ошибка; законное «Дио» допускается только в собственной строке приветствия. Неудачная строка требует адресного разбора, а не скрытого исправления ASR.

MP3 — mono 24 kHz / 128 kbit/s. Удаляется только внешняя тишина с запасом 80 ms, внутренние паузы сохраняются. Двухпроходный loudnorm повторяет B: цель −18 LUFS / −1,5 dBTP / LRA 11, fades 6/12 ms. Нет ускорения, pitch shift или нарезки исходных слов в новую реплику. Каталог использует фактические длительности; старые `maxDuration` не ограничивают запись.

Тексты, исходный ASR, seed, длительности, уровни, тишина, SHA MP3/raw WAV и история повторов — в `scripts/voice-production/jotaro-pack-analysis.json`. Поле `userListeningApproved` всего пакета — `false`; `true` имеет только скопированный B. Каталог выпускается после проверки всех 28 строк и хешей. Измерения не доказывают художественное качество. Сырые WAV и архив заменённых файлов лежат вне production в `C:/Temp/hsr-jojo-tts/jotaro-approved-production/`.

Итог: **28/28 точных последовательностей слов**, без исключений и клиппинга. Первоначально ASR распознал «изборку» вместо «сборку» в `round-warranty-setup-p1` и слитое «полуже» вместо «пол уже» в `round-floor-setup-p1`; только эти два дубля повторены с **seed 62201**, сохранив тот же источник и `synthesisText`. Оба повтора прошли точную проверку. Отвергнутые попытки сохранены в `attemptHistory`, ASR не исправлялся вручную.

Все **28 прежних p1 MP3 заменены**, что проверено по SHA; B совпадает с принятым файлом. Размер — **1 240 784 байта**, суммарно **75,221958 с**, диапазон длительностей **1,20–4,46 с**, максимум предраундовой записи **3,95 с**. Громкость −18,63…−18,43 LUFS, максимум true peak −3,29 dBTP. Повторное декодирование всех MP3 и SHA сырых WAV новых генераций прошли. Проверки проекта: **500/500 тестов**, production build. Сценарные данные p2 побайтно/структурно не менялись, их каталог и аудиофайлы остались прежними.

## Воспроизведение из чистого checkout

```powershell
$voicePython = 'C:/Temp/hsr-jojo-tts/venv/Scripts/python.exe'
& $voicePython scripts/voice-production/generate-jotaro-pack.py `
  --model C:/Temp/hsr-jojo-tts/models/qwen3-tts-1.7b-base `
  --asr-model C:/Temp/hsr-jojo-tts/models/whisper-large-v3-turbo `
  --work C:/Temp/hsr-jojo-tts/jotaro-approved-production
```

Скрипт принудительно использует offline-режим и проверяет SHA исходника, веса и принятого MP3. Аудио наружу не отправляется. Источник уже в Git, B по умолчанию читается из собственного production-пути; совпадение source/destination проверяется, исключая `SameFileError`. Не нужны отвергнутые WAV, старые worktree или исследовательские assets. Точные версии библиотек записаны в отчёте. На другой машине меняются только пути к Python, моделям и внешнему `--work`.

`--phase asr` повторяет только распознавание; `--phase finalize` проверяет готовый отчёт/ресурсы без синтеза. `--only <ID>` ограничивает адресный повтор; иной `--seed` разрешён только с этим ограничением. `--asr-device cpu` переносит только распознавание на CPU. Смена рецепта требует полного нового пакета, чтобы не смешивать голоса. Seed не гарантирует одинаковые байты на другом GPU/версиях библиотек; сохранённый B всегда остаётся неизменным.

Для воспроизведения принятых адресных повторов после первого полного прохода повторить команду с `--only round-warranty-setup-p1,round-floor-setup-p1 --seed 62201`. Остальные 26 готовых файлов не пересинтезируются.
