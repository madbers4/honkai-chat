# JoJo v3: новая дуэль роботов

Машиночитаемый источник — [spoken-script.json](../scripts/voice-production/spoken-script.json), версия `club-spoken-jojo-v3`. Это 57 записей: девять для противостояния и 48 для двенадцати предраундовых пар; 33 смысловые строки целиком новые относительно v2. Для p1 — 28 файлов, для p2 — 29. Ни один разговорный MP3 из v2 не перенесён. Методы, выбранные пробы и итоговый отчёт описаны в [JOJO-AUDIO-V3.md](JOJO-AUDIO-V3.md).

Сцена — смешная дуэль машин, которые играют Джотаро и Дио: один приближается и отвечает по делу, другой требует внимания к своему величию. Отсылка развивается через позу, расстояние до удара и короткие колкости о металлическом корпусе. Фразы об остановке времени условные: «я бы». Они не обещают игроку новую способность.

Сценарий подготовлен на базе `ce1b233`. Этот документ описывает тексты; фактические записи, длительности и границы проверки хранятся отдельно в итоговом аудиоотчёте.

## Что меняется и что сохраняется

- Полностью заменены девять реплик противостояния и двенадцать предраундовых перепалок. Убраны прежние темы боевого режима, гарантии, чайника и пакета пафоса.
- Сохранены все структурные faceoff/round IDs, порядок девяти ходов и матрица двух голосов для каждой предраундовой строки.
- `PREMATCH_EXCHANGES` содержит те же новые тексты для карточек и суфлёра. Старые привязки `clips` удалены: прежний звук не соответствует новым словам.
- Авторский устав, правила боя, 210 реплик живого рефери, пользовательские именные карточки и исходные боевые эффекты ORA/MUDA, атак, суператаки и взрыва остаются прежними.
- Джотаро и Дио называются только в первых двух репликах как роли этой пародии. Выбранные игроками имена показываются в карточках; динамический синтез имён не заявляется.

## Два постоянных мужских голоса

**p1 — Джотаро.** Собранный взрослый мужской голос, короткая адресная угроза, сухой юмор. Слова направлены противнику: сначала оценка, затем резкий смысловой нажим. В ответах часто достаточно спокойного конца, чтобы обесценить чужую браваду. Не превращать каждую строку в одинаковый протяжный крик.

**p2 — Дио.** Взрослый мужской голос, театральная уверенность и удовольствие от собственной наглости. Насмешливое любопытство может резко переходить в возмущение. Говорит сопернику, а не читает анонс; смешок допустим в окраске, но отдельные слова и междометия не добавляются.

Голос закреплён за p1/p2. Очерёдность, имя робота и сторона экрана не меняют исполнителя. Это требование к новым записям, а не обещание, что модель автоматически сохранит тембр и пол на каждом дубле: результат проверяется отдельно.

`text` — каноническая произносимая последовательность слов и субтитр. `synthesisText` — точный ввод для синтеза: те же слова, с отдельной пунктуацией и регистром для каждого голоса. Капсом выделено смысловое слово, а не вся строка. `emotionalDirection` содержит темп, паузу, нажим и актёрскую задачу; эти указания нельзя приписывать к произносимой фразе. Они не объявляются поддерживаемыми параметрами TTS, если модель их не принимает.

## Девять ходов противостояния

| ID | Голос | Точный текст | Действие голосом |
| --- | --- | --- | --- |
| `faceoff-mode-p1` | p1 | Дио. Сегодня гнётся не моя броня. | Имя отдельно; спокойно определить, чей корпус пострадает. Нажим на «моя». |
| `faceoff-mode-p2` | p2 | Джотаро! Подвал маловат для моего величия! | Узнавание с всплеском; сразу присвоить себе всю сцену. Нажим на «моего». |
| `faceoff-greeting-open` | p2 | Ты приближаешься? Выход в другой стороне. | Удовольствие от дерзости, затем снисходительное указание на выход. |
| `faceoff-greeting-answer` | p1 | Я иду туда, где надо ударить. | Прямой ответ без суеты; угроза заключена в последнем глаголе. |
| `faceoff-greeting-package` | p2 | Какая дерзость! Даже твои винты дрожат! | Оскорблённое величие превращается в попытку запугать. |
| `faceoff-challenge-p1` | p1 | Это твой корпус. Мой уже рядом. | Исправить соперника сухой первой фразой; второй сократить дистанцию. |
| `faceoff-taunt-p2` | p2 | Я бы остановил время ради этой позы! | Самовлюблённая фантазия с нажимом на «позы». |
| `faceoff-resolve-p1` | p1 | Сначала останови болтовню. Потом позируй. | Срезать размах конкретным предложением. Последнее слово без распева. |
| `faceoff-fight-p2` | p2 | Подходи, железный нахал! Муда! | Резкий вызов и короткое последнее слово. |

Старые ID `mode` и `package` сохраняются только как технические ключи: они больше не обозначают прежнее содержание. Ни одной реплике не приклеивается старый таймкод. `maxDuration` в JSON — ориентир для планирования, а не потолок монтажа. После генерации окно строится по измеренной полной длительности файла; начала, окончания и выразительные паузы не обрезаются, речь не ускоряется ради прежнего слота.

Каждая строка записывается обоими голосами. Канонический текст одинаков, смысловой нажим может различаться. Например, p1 спрашивает «Что громче: ОРА или муда?», p2 — «Что громче: ора или МУДА?!». Слова одни и те же, но каждый отстаивает своё. В ответе про вмятину p1 прикидывает место удара, p2 наслаждается перспективой испортить сопернику вид. Полная режиссура всех 57 вводов сохранена в JSON.

Шутки построены как завязка → ответ. Хвастовство необязательно принадлежит Дио: сдержанный p1 произнесёт его как установленный факт, а p2 ответит с насмешкой. Поэтому пара работает при обеих очередностях:

| Очередность | Первое окно | Второе окно |
| --- | --- | --- |
| Нечётный раунд | `round-<pair>-setup-p1` | `round-<pair>-reply-p2` |
| Чётный раунд | `round-<pair>-setup-p2` | `round-<pair>-reply-p1` |

Пару выбирает существующий детерминированный deck; потом выбираются смысловой ход и голос. Нельзя начинать с reply лишь потому, что первым говорит другая машина. Сохранены все `playOrder.odd/even`. Время каждого окна определяется фактическим MP3 с запасом на старт 0,38 с и остатком 0,12 с; прежние 2,95 с не ограничивают новый файл.

При подключённом рефери автоматические предраундовые реплики подавляются. Суфлёр показывает новую выбранную пару с текущими именами машин; остальные реплики рефери не переписаны.

## Голосовые рецепты

| Голос | Источник | Фрагмент | Точный reference text |
| --- | --- | --- | --- |
| p1 | `public/assets/voices/jotaro-dio.mp3` | Полный файл, 0–4,284979 с | Ублюдок! Дио! |
| p2 | `public/assets/voices/greeting.mp3` | 7,70–11,32 с, только один исполнитель | Что ты мне сделаешь, а, Джотаро? |

Для p1 используется выбранная новая проба **А на CosyVoice3**: zero-shot по полному исходному «Ублюдок! Дио!». Для p2 — ранее одобренный рецепт full ICL Дио на Qwen3-TTS. **Выбраны голосовые пробы; все 57 записей этим не объявляются прослушанными или одобренными.** Первая новая реплика p1 сохраняет ровно выбранный Cosy-пилот А; старые v2 MP3 не копируются. Отвергнутый Qwen-Джотаро не применяется.

Полный `greeting` содержит двух актёров и не подходит как единый голосовой anchor. Неактивные кандидаты в разделе `references` JSON — сохранённое происхождение исследования; действующие `primaryReference`/`utterances[].reference` указывают на два рецепта из таблицы.

## Передача в производство

Готовый пакет должен содержать все 57 новых файлов с прежними ID и правильными `speaker`. Общий каталог подключается целиком после производства; нельзя смешивать новый сценарий с половиной старых разговорных записей. Сценарный коммит сам не меняет аудиокаталог, контроллер, браузерный TTS или камеру. Завершённый выпуск требует отдельного обновления аудио и runtime-проверки.

Для каждого дубля сохраняются точный `synthesisText`, модель, seed, исходный WAV и фактическая длительность. ASR без подсказки целевого текста сверяет слова и возможную утечку reference text; имена и «ора/муда» требуют внимательной трактовки ошибок распознавания. Уровни, тишина и клиппинг проверяются отдельно. ASR и измерения не подтверждают эмоциональность, мужской тембр или сходство с исходным актёром — для этого нужно прослушивание.

Приёмка интеграции: все девять ходов подряд, обе очередности каждой пары, имена только на карточках, ни одной старой разговорной реплики, отсутствие смены голоса на системный женский TTS, целые начала и окончания без наложений. Старые эффекты боя и авторский устав проверяются на сохранность отдельно.
