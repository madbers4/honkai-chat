# Искра в эфире · Фонтейнка

Статическая игра для зоны Пенаконии на CONstanta. Гость сканирует QR на реквизитной бомбе, переписывается с Искрой от лица Первопроходца и играет в маленького «Сапёра» прямо в чате.

## Правила

- Пять минут на диалог и игру вместе. Отсчёт начинается после кнопки «Войти в эфир».
- Пять попыток, включая первую. Попадание на мину тратит попытку, вызывает комментарий Искры и позволяет начать новое поле; время не сбрасывается.
- Поле 5 × 5, четыре мины. Первый ход и соседние клетки безопасны. Цифры учитывают восемь соседей. Для победы нужно открыть все безопасные клетки.
- В дереве 38 диалоговых узлов и 102 пути к игре; один разговор занимает 4–8 ответов. Искра вспоминает выбранную манеру общения после ошибок.
- При победе площадка спасена. После пяти ошибок или истечения времени — сюжетный взрыв конфетти. Оба финала предлагают показать экран стендовику и получить печать.

## Запуск

Node.js 20+.

```sh
npm ci
npm run dev
```

Открой адрес, который напечатает Vite. Для просмотра с телефона в той же сети: `npm run dev -- --host 0.0.0.0`.

```sh
npm run build
npm run preview
```

Готовый сайт — `client/dist/`. Его можно разместить на любом статическом хостинге; игровой сервер, API, WebSocket, база данных и авторизация не нужны. После загрузки игра работает без сетевых запросов к бэкенду. Холодное открытие сайта требует доступа к его файлам.

## Сессии и QR

Игра сохраняется в `sessionStorage` текущей вкладки после каждого действия: переписка, поле, начало и конец отсчёта, использованные попытки, результат. Обновление страницы восстанавливает ту же партию; время продолжает идти в фоне. Новая вкладка обычно начинает новую сессию, но браузер может скопировать сохранение при дублировании вкладки или восстановить её после закрытия. Вкладки не синхронизируются. Это локальный игровой прогресс, не защита от намеренного сброса.

Страница `/?staff=1` создаёт PNG с QR на введённый публичный адрес. Корневой адрес сайта достаточен, секретные параметры не нужны. Старые пути `/guest` и `/actor` также поддерживаются на хостинге с SPA fallback.

Эфир, его зрители и комментарии Искры — художественная часть игры. Камера и микрофон не используются, сообщения никуда не отправляются.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium --only-shell
npm run test:e2e
```

Тесты проверяют всё дерево диалогов, границы поля, безопасный первый ход, ровно пять попыток, таймер, победу, восстановление после перезагрузки, независимость сессий, мобильный интерфейс, игру без сети после загрузки и содержимое QR-кода.

## Редактирование

- `client/src/game/dialogue.ts` — все реплики и ветки. `game` в поле `next` открывает сапёра.
- `client/src/game/game.ts` — переходы состояний, время, попытки и финалы.
- `client/src/game/minesweeper.ts` — поле и правила сапёра.
- `client/src/game/SparxieGame.tsx` — интерфейс, сессионное сохранение и QR.
