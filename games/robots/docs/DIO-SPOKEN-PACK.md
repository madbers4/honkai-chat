# Разговорный пакет p2: одобренная подача Дио

29 записей второй машины: пять реплик кат-сцены и обе разговорные роли в двенадцати предраундовых парах. Каталог — `shared/generated-dio-voice-clips.js`, метрики и история адресных повторов — `scripts/voice-production/dio-pack-analysis.json`. URL имеют отдельную версию `/assets/voices/spoken-v2/<id>.mp3`; старые записи и боевые эффекты не перезаписаны. Runtime, расписание и общий voice manifest интегрируются отдельно.

`faceoff-mode-p2` — байтовая копия одобренного пользователем «Дио — выразительный референс» (`dio-b-icl.mp3`). SHA-256: `639de7c08eddd6c2aff517a6d0edc4f316e1a47c697c58e87f0137d7e43a1ed1`. Текст: «Твой гарантийный талон уже мёртв!», фактическая длительность 2,63 с. В производственном сценарии изменено только поле `text` этой реплики, чтобы оно совпадало с принятой записью.

Остальные 28 файлов синтезированы локально тем же рецептом: Qwen/Qwen3-TTS-12Hz-1.7B-Base, revision `fd4b254389122332181a7c3db7f27e918eec64e3`, full ICL (`x_vector_only_mode=False`), BF16, SDPA. Референс — присланное приветствие `public/assets/voices/greeting.mp3`, фрагмент **7,70–11,32 с**, `ref_text`: «Что ты мне сделаешь, а, Джотаро?». Это одна реплика p2; целый двухголосный greeting не подаётся в модель. Промежуточный reference WAV квантуется в PCM16 точно как в пилоте.

Первый дубль каждой строки использует seed 62202. Параметры генерации: Russian, non-streaming, `max_new_tokens=240`, `do_sample=True`, `temperature=.9`, `top_k=50`, `top_p=1`, `repetition_penalty=1.05`. Режиссёрская пунктуация остаётся в произносимом тексте; служебные указания не читаются. Случайного массового поиска дублей нет: другие seed применяются только к конкретным строкам, не прошедшим проверку, и сохраняются в отчёте.

Изменения высоты или темпа нет. Обрезана только внешняя тишина с запасом 80 мс; короткие fades и двухпроходный loudnorm повторяют пилот: −18 LUFS, target true peak −1,5 dB, LRA 11. Формат MP3 mono 24 kHz / 128 kbit/s. В каталоге указаны реальные декодированные длительности. Старые сценарные `maxDuration` — ориентир предыдущего задания, а не причина ускорить или обрезать новую актёрскую реплику. Расписание должно учитывать выбранную запись целиком и задержку запуска.

## Проверка

Каждый MP3 декодируется заново. Проверяются конечный PCM, формат, отсутствие клиппинга, пиковая громкость и внешняя тишина. Независимый локальный Whisper large-v3-turbo (`41f01f3fe87f28c78e2fbf8b568835947dd65ed9`, русский, beam=5) распознаёт файл без подсказки целевого текста и без контекста предыдущей записи. Сравнение сохраняет порядок и границы слов; игнорирует только регистр, пунктуацию и ё/е. Добавленная речь референса считается ошибкой; разрешённое «Джотаро» в собственной строке приветствия не считается утечкой.

Отчёт содержит полный результат ASR, точный текст, seed, SHA-256, длительность, громкость, тишину и результат каждого критерия. Отбракованные попытки остаются в `attemptHistory`; их аудио и сырой WAV находятся вне репозитория. Каталог выпускается после технической проверки всех 29 файлов, проверки текста с указанным ниже единственным исключением и повторного совпадения SHA файлов с метриками.

Результат: **28/29 точных последовательностей слов; одна документированная орфографическая неоднозначность имени**. Первоначальное «Лучшая розетка» вместо «Лучше розетку» было реальным расхождением; только этот дубль и приветствие повторены seed 62302. Повтор про розетку полностью совпал с текстом.

Итоговый пакет занимает 1 145 596 байт; длительности 1,29–3,40 с, самый длинный предраундовый файл — 2,91 с. SHA и соответствие каталога сценарию проверены для всех 29 файлов. На этой ветке проходят **486/486** тестов проекта и production build; игровой проигрыватель ещё не подключён к новому каталогу.

В `faceoff-greeting-open` Whisper turbo и независимый CPU Whisper small (beam 1 и 5, без подсказки текста) согласованно дают «Вот мы и встретились, Джотара». Все слова, кроме написания безударного окончания имени, совпадают. Окончательное /о/ в русском произношении может редуцироваться до звука, распознаваемого как «а»: это **фонетическое объяснение, не утверждение о прослушивании**. По результату отдельного разбора разрешена только замена написания `Джотара → Джотаро` в этой единственной строке и только при точном совпадении остального текста в независимых распознаваниях. `exactWordMatch` остаётся **false**, исходный ASR не исправлен и сохранён вместе с `nameSpellingException`. Это не общая поблажка к опечаткам, лишним словам или другим репликам. Текущий дубль seed 62302 нужно включить в слуховую приёмку целой сцены; дальнейшего поиска seed ради орфографии не проводилось.

Одобрен на слух пользователем именно скопированный пилот. Для остальных файлов технические проверки и ASR **не означают**, что все дубли прослушаны или что актёрское сходство подтверждено. Слушательская приёмка всей постановки остаётся отдельной частью интеграции.

## Воспроизведение

Используется локальное окружение Python из `C:/Temp/hsr-jojo-tts/venv`; точные версии пакетов записаны в `runtime.packages` отчёта. Зависимости и веса хранятся вне проекта. Скрипт принудительно включает offline-режим и не скачивает модели. Нужны локальные Qwen Base и Whisper large-v3-turbo, CUDA, а также одобренный MP3 с указанным SHA. GPU не запускать одновременно с другим генератором.

Из корня проекта:

```powershell
$voicePython = 'C:/Temp/hsr-jojo-tts/venv/Scripts/python.exe'
& $voicePython scripts/voice-production/generate-dio-pack.py `
  --model 'C:/Temp/hsr-jojo-tts/models/qwen3-tts-1.7b-base' `
  --asr-model 'C:/Temp/hsr-jojo-tts/models/whisper-large-v3-turbo' `
  --pilot 'public/assets/voices/spoken-v2/faceoff-mode-p2.mp3' `
  --work 'C:/Temp/hsr-jojo-tts/dio-production' `
  --name-check-model 'C:/Temp/hsr-jojo-tts/models/whisper-small-direct'
```

Первый проход ожидаемо останавливается с двумя отмеченными выше строками; он не публикует неполный каталог. Для воспроизведения принятых адресных повторов повторить команду, добавив `--only faceoff-greeting-open,round-polite-reply-p2 --seed 62302`. Прошедшие 27 записей при этом не синтезируются снова.

Параметр `--phase asr` повторяет только распознавание существующих файлов; `--phase finalize` проверяет полноту/хэши и собирает каталог без синтеза. `--name-check-model` включает независимую CPU-проверку только узкой неоднозначности имени; без неё несовпавшая строка не проходит. `--asr-device cpu` позволяет выполнить основной ASR без CUDA; генерация всегда требует CUDA. Пилот при любой выбранной фазе синтеза копируется, не пересоздаётся. Повтор на другом GPU/версии библиотек может дать иной дубль и иные ошибки; фиксированные seed — рецепт, а не гарантия тождественных байтов на любом окружении.

Генератор не меняет сам сценарий, глобальный manifest, громкость игры, таймлайн, голос p1 или эффекты. Каждый файл принадлежит p2 даже тогда, когда произносится первым в чётном раунде.
