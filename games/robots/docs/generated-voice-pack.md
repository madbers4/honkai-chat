# Короткие реплики роботов: офлайн voice pack

Шесть MP3 в `public/assets/voices/generated/` — новая речь, синтезированная локально по двум предоставленным звуковым референсам. Готовый manifest: `shared/generated-voice-clips.js`, экспорт `GENERATED_VOICE_CLIPS`. Серверу и телефону для воспроизведения не нужны Python, модель, GPU или внешний TTS API. Исходные игровые аудиофайлы и их manifest этим пакетом не заменяются.

## Реальный способ генерации

Использована [Qwen3-TTS-12Hz-1.7B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base), revision `fd4b254389122332181a7c3db7f27e918eec64e3`. Модель поддерживает русский язык и синтез по голосовому образцу. Код и веса Qwen опубликованы под Apache-2.0; описание API находится в [официальном репозитории Qwen](https://github.com/QwenLM/Qwen3-TTS). Лицензия модели не является лицензией исходных пользовательских записей и не означает одобрения проекта их исполнителями.

Референсы взяты из переданной пользователем папки `звуки`: «Джот - Похоже ты и правда не прост.mp3» и «Дио - Ха, ну вперед, Герой.mp3». Их SHA-256, границы обрезки и все настройки каждого дубля записаны в `generated-voice-pack-analysis.json`. Внешним API записи не отправлялись.

Выбран `create_voice_clone_prompt(..., x_vector_only_mode=True)`: модель извлекает признаки голоса из записи, затем создаёт новую речь. Полная транскрипция исходника не подставлялась: распознавание японского междометия в русской записи было ненадёжным. Это не монтаж старых слов, не изменение высоты оригинальной записи и не браузерный speechSynthesis. Тембр и выразительность являются приближением; короткий режим x-vector не гарантирует сохранение актёрской подачи или точного сходства.

Синтез: Windows, RTX 4080 16 GB, Python 3.12.14, BF16, SDPA, `max_new_tokens=180`, seed отдельно для каждой реплики. Пик выделенной CUDA-памяти около 4,32 GB. Один дубль с кодированием занимает примерно 4–6 секунд после загрузки модели. FlashAttention и SoX не потребовались: референс передаётся как PCM-массив, SDPA работает средствами PyTorch. Пакет Qwen может печатать предупреждения об этих отсутствующих необязательных компонентах.

## Воспроизведение сборки

Все зависимости и многогигабайтные веса устанавливаются **в отдельный каталог вне репозитория**. Ниже `C:\Temp\hsr-jojo-tts-repro` — пример такого каталога; используйте установленный Python 3.12.

```powershell
python -m venv C:\Temp\hsr-jojo-tts-repro\venv
$voicePython = 'C:\Temp\hsr-jojo-tts-repro\venv\Scripts\python.exe'
& $voicePython -m pip install torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu128
& $voicePython -m pip install qwen-tts==0.1.1 transformers==4.57.3 accelerate==1.12.0 huggingface-hub==0.36.2 imageio-ffmpeg==0.6.0 soundfile==0.14.0 numpy==2.5.3 librosa==1.0.0
& $voicePython -c "from huggingface_hub import snapshot_download; snapshot_download('Qwen/Qwen3-TTS-12Hz-1.7B-Base', revision='fd4b254389122332181a7c3db7f27e918eec64e3', local_dir='C:/Temp/hsr-jojo-tts-repro/model')"
```

Из корня репозитория:

```powershell
& $voicePython scripts/generate-jojo-voice-pack.py --reference-dir E:\hsr-robots-battle\звуки --model-dir C:\Temp\hsr-jojo-tts-repro\model --work-dir C:\Temp\hsr-jojo-tts-repro\work
```

Для одного пробного дубля добавьте `--only jotaro-mode --output-dir C:\Temp\hsr-jojo-tts-repro\pilot`. Manifest при одиночном запуске не перезаписывается. После загрузки весов скрипт работает с `HF_HUB_OFFLINE=1`. В нём нет автоматических повторов генерации; тишина, слишком длинный дубль, NaN или клиппинг завершают запуск с ошибкой. Фиксированные seed дают воспроизводимые дубли на указанном окружении; другие CUDA/PyTorch/GPU могут изменить результат.

Независимое распознавание необязательно. Для него использован [faster-whisper](https://github.com/SYSTRAN/faster-whisper) 1.2.1 и локальная модель [Systran/faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small), CPU/int8. После её отдельной загрузки передайте `--asr-model-dir <локальная-папка-модели>`. ASR не получает целевой текст как подсказку.

## Проверка готовых файлов

Формат: MP3, mono, 24 kHz, 96 kbit/s. Обрезана только внешняя тишина с запасом 80 ms; добавлены короткие противощелчковые fades. Двухпроходный loudnorm ориентирован на −16 LUFS, true peak ≤ −1,5 dB до MP3. Два длинных предбоевых дубля ускорены без изменения высоты голоса на 10,07% и 4,70%, чтобы длиться меньше трёх секунд.

Все шесть файлов декодируются в конечный PCM, клиппинга нет, тишина на краях 10–80 ms. Whisper независимо подтвердил пять реплик дословно; в «Лови искру» ошибочно разделил последнее слово на «и скру», сохранив последовательность звуков/букв. Нормализованная проверка текста игнорирует пробелы, пунктуацию и ё/е; исходная транскрипция сохранена в отчёте, поэтому эта проверка не скрывает ошибку сегментации.

Для каждого результата также вычислено сходство speaker embedding с обоими референсами: собственный образец ближе во всех шести случаях. Это техническая диагностика применения референса, **не процент сходства на слух**. Автоматические измерения и ASR не заменяют прослушивание: художественная оценка тембра/актёрской подачи этим отчётом не утверждается. Это короткий готовый набор для интеграции и слухового просмотра, а не серверный синтез произвольных имён игроков.
