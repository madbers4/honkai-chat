# Размещение двух игр

`/` — существующая «Искра в эфире»; `/robots/` — Новый Бойцовский клуб. Старые `/guest`, `/actor`, `/?staff=1` остаются доступны. Игры используют отдельные ресурсы и локальные сохранения.

## Локальный запуск общего сервера

Для сборки нужен Node.js 22.12+, для готового сервера — Node.js 20+.

```sh
npm ci
npm test
npm run build
npm start
```

Открыть `http://localhost:3001/` или `http://localhost:3001/robots/`. Порт меняется через `PORT`. QR-приглашения роботов ведут на `/robots/?room=…`; HTTPS и `wss` выбираются из адреса браузера. На localhost предлагается адрес локальной сети.

`npm run dev` и `npm run preview` по-прежнему относятся к клиенту Искры; для обеих игр использовать сборку и `npm start`.

## Существующая виртуальная машина

Workflow `.github/workflows/deploy.yml` запускается после push в `main` или вручную. Использует прежние Secrets `VM_HOST`, `VM_USER`, `VM_SSH_KEY`. Сначала тестирует и собирает обе игры, затем загружает отдельный выпуск в `/opt/honkai-chat/releases/<commit>`.

`activate-release.sh` устанавливает только production-зависимости, переключает `current`, заменяет PM2 static serve на один Node-процесс `honkai-chat` и сохраняет **порт 3001**. Остальные процессы PM2 не изменяются. Node и PM2 уже должны быть установлены; глобальные инструменты скрипт не обновляет. Выпуски и старый `client/dist` сохранены. При неуспешной проверке восстанавливается предыдущий выпуск, а при первом переходе — прежняя статическая раздача.

Проверка запуска запрашивает обе страницы, модель и JS, затем соединяет двух настоящих WebSocket-клиентов. Команда для повторной проверки, включая внешний домен:

```sh
node scripts/smoke-host.mjs https://your-existing-domain.example
```

## Обратный прокси

Существующий прокси должен передавать путь целиком на `127.0.0.1:3001`, включая `/robots/`, и поддерживать WebSocket upgrade. Если раньше раздавалась только статика, для nginx требуется:

```nginx
location / {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 120s;
}
```

Файл nginx автоматически не перезаписывается. При прямом доступе к порту 3001 дополнительный прокси не нужен.

## Эксплуатация

Один процесс хранит комнаты в памяти; рестарт завершает текущие бои. Для живых матчей нельзя включать несколько PM2 workers без общего хранилища. Главная игра продолжает работать локально после загрузки.

Для отката на проверенный выпуск:

```sh
bash /opt/honkai-chat/releases/<previous-40-character-commit>/scripts/activate-release.sh <previous-40-character-commit>
```

Исходная игра отдельно по-прежнему может публиковаться статически из `client/dist`; для сетевого Бойцовского клуба требуется общий Node-сервер.
